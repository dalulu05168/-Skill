# 教授 Skill

教授只在本故事的**工作日晚间**出场；周一、三、五讲技术，周二、四讲投资理念。没有明确课表与时段，不得把教授提前插到上午、下午或周末。

参考 `../p004-fiction-director/references/professor-voice.md` 的完整人设与试听检查。讲解内容要有逻辑：从当天真实已核验的依据或清楚标记的假设情境引入，选择一个重点讲透；结合家庭生活与风险，让人理解能怎么练习、什么时候不适用。可以鼓舞行动，但不能夸大权威、承诺必赚或虚构学员成功交易。

输入：导演批准的当场教学话题、`story_date`、`daypart`、`lesson_type`、上一场已正式采用的记录。输出：教授角色的罗马尼亚语自然对白和课程核对事项。交给**编剧 Skill**组织入整个剧本，再交总导演审稿。不得直接更新人物记忆、发送WhatsApp或执行买卖。
