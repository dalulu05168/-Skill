入口：SKILL.md。此包已包含65份完整角色档案、市场规则、导演规则、八项穿插规则、八周理念课程计划、模板及示例。

使用：在支持自定义Skill的平台，通过平台提供的导入入口导入该目录或ZIP。不同平台安装方式不同，本次只生成可移植资料包，不声称已在账户中安装启用。

若平台不支持Skill导入，上传资料包并要求AI读取SKILL.md；选择角色后读取对应完整档案。

示例请求：
- 整理今天上午的罗马尼亚优先财经资讯与指标，再编排虚构剧本。
- 准备本周四的投资理念课，接上上一堂的仓位主题。

联网检索依赖执行平台提供工具，本包不含行情API或密钥。没有工具时需用户提供资料或明确报告待核验。定时运行、自动群发、永久记忆均未配置。

所有剧本是明确标注的虚构演绎。不处理买卖指令，不伪造独立客户背书、盈利见证或隐瞒身份的第三方互动。
