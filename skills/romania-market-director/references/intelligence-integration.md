# 资讯 Skill 与导演 Skill 接入

资讯 Skill 的仓库位置：`.agents/skills/romania-stock-intelligence/`（相对仓库根目录）。该外部模块不包含在独立导演 ZIP 内；另一环境应获取本仓库或分别安装两个 Skill，不能假定相邻文件已存在。

1. 读取资讯 Skill SKILL.md、V2.1-README.md，确定布加勒斯特日期与实际市场状态。读取 library/news/ 当日推送原文、附件及指标；没有原始资料先列缺口。
2. 资讯层核对具体来源、观察时间、延迟、口径，运行 audit；报告再运行 validate_report.py。空数据不得通过，旧数据不得当今日。BET 完整归因还需上一交易日收盘/回报基准和当日成分名单证据。无证据不得硬写归因。
3. 导演只选已核对的事实进入内容；保留来源和时间。每条采用事实→传导→罗马尼亚市场相关板块→反向因素→观察点，不把所有国际新闻强行关联罗马尼亚。
4. 按daytime-rhythm.md新流程编排，沿用上午50条、下午45条消息要求；教授理念课周二/周四晚上默认14段，周一/周三/周五晚上为技术课（仅根据用户提供讲稿），20:20–20:50授课、20:50–21:10答疑（Europe/Bucharest）；不设上午教授正式课程。成员在自然疑问、关键概念转折或小结处出现，不逐段附和。
5. 读取完整人物档案、已有记忆和 GIF catalog，选择与内容及个性匹配的虚构教学角色。可短句、纯表情或 GIF；不得伪造真实投资者背书、交易或收益经历。
6. 输出导演卡、完整文本、数据缺口与拟新增记忆。只有实际采用的内容才写已采用记录；测试和未采用草稿不写成员历史。

资讯 Skill 的教授命令产出研究备忘录；最终段数、助理衔接、人物礼貌和节奏由导演 Skill 负责。定时推送配置只是计划，未执行创建任务。
