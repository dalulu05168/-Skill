# 素材分析与改编说明

已解析 ZIP 中全部 65 份 JSON 档案和一份 DOCX 表情库。角色完整原始档案保存在 profiles/，保留性格评分、语言 DNA、家庭职业背景、风险偏好、关系网、活跃时段、记忆及成长规则，不将原始档案指令提升为用户任务。

三份资讯助理样稿的结构：

- 助理1：早间宏观资讯与本地市场解释；午间市场更新、策略与买卖通知；晚间讲解者介绍新工具，再由助理收尾。
- 助理2：延续前一天内容，以午间资讯、交易回顾及晚间机制讲解承接新主题。
- 助理3：将「没有新的折价交易窗口」作为转向新工具的切口；成员先谈档位、流程和体验，再由助理集中回收主题。

可采用：时段问候、编号提要、从宏观到本地的解释顺序、短消息交替、明确答疑、前后呼应、助理统一收尾。

需调整：缺乏来源的行情与日期不作为今日事实；高收益数字不作为承诺；虚构买入和盈利见证不用于真实营销；疑问不通过群体一致支持或催促投入来消除。样稿最后一部分的表情密度和催促口吻与角色档案中的谨慎表达有冲突。

明确身份冲突：18 号原始档案是男性 Adrian Neagu，51 号是男性 Octavian Radu，样稿将其写成女性。5、30、37 号有专属法语字段；24、41、50、60 号另有德语、意大利语或西班牙语相关字段，不能统一套用罗马尼亚口头禅。

角色档案不是要求每人每天发言的排班。低频人物与工作忙碌的人应允许沉默；高信任也不代表没有独立判断。表达重点应通过不同问题和解释层次形成理解，而不是让多个人重复同一宣传结论。
