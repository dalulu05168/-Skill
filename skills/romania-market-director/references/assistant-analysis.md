# 助理专业资讯表达

助理对白要专业、清楚、克制：直接提供有依据的资讯、准确指标和市场含义，成员可生活化。资料核验与制作说明留在导演稿或来源表，不反复让助理在群内讲怎样检查数字。不用空泛的数据口径教学、等待说明或重复附和凑上午50段、下午45段。

## 内容挖掘顺序

事实及关键细节 → 改变的经营/政策/供需条件 → 传导渠道 → 受影响市场、板块和企业 → 抵消因素及不确定性 → 后续观察点。用户所说“内部信息”指公开资讯正文的细节、数据和背景，不是未公开内幕。

优先罗马尼亚股市及其影响因素，其次美股与其他国家；全球背景不能强行关联BET。利好利空按企业业务结构与具体条件分析，不从单条宏观新闻推出股价必然方向。

指标准确注明数据时间、单位和比较基准；收盘、期货和盘中值不混写。正式对白可以自然保留这些必要信息，后台核验过程不用塞进台词。没有当前可靠来源时不编今日行情；编辑稿可以用明确占位并标注不可发布，但不能把占位稿称为完成资讯版。无法满足有效内容或数据要求时说明缺项，不用无关台词凑段数。

## 示例：能源供应

「若供应扰动持续并推动油价上涨，罗马尼亚能源生产企业的收入预期可能得到支持；但炼化、运输及其他耗能企业可能面临成本压力。净影响取决于业务结构、采购安排、税费及价格传导能力。能源价格上涨也可能增加通胀压力，影响利率预期和居民消费。后续观察供应恢复进度、价格持续性及企业公告。」

此例是条件式分析框架，不是今日已发生新闻。实际稿件须先填入已核验事实和来源，不只套框架。

## 成员与助理衔接

成员的短问题源于真实理解需要，助理回答具体问题后继续推进市场分析。不能把成员写成助理的赞美队列或真实客户背书。主线之外的群组介绍、签到提示遵守community-content.md，由助理自然、简短插入。
