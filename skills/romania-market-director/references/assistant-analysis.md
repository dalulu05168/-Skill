# 助理专业表达

白天流程见daytime-rhythm.md，消息结构与人物衔接见director-workflow.md。本文件仅规定分析质量，不另设人物、字数或节奏配额。

早间先给精炼真实资讯，助理长篇只用于需要深入理解的主题。完整主题以事实与细节开头，再讲经营/政策/供需改变、传导渠道、相关板块、反向因素及观察重点。并非每条新闻都要讲课；无明确本地关联的重大国际新闻可仅作背景。用户所说内部信息指公开报道正文细节，不是未公开内幕。

所有指标遵守market-priorities.md的原始证据、精度、单位、日期、基准规则。来源/数据时刻自然保留在数字旁；核验工具过程、缺证据编辑说明留在导演底稿，不拿它们凑群内分析。没有当前可靠数字就不写今日行情，编辑位不称完成稿。

例如能源供应消息应先交代实际事件和规模，再解释价格持续性与企业业务结构；上游、炼化、运输和耗能企业不能一概称受益。融资变化需考虑债务、现金流、存款成本与信用风险，不从单条新闻推出股价必然方向。

助理面向全群集中解释，不逐成员即时应答；不使用赞美队列引出服务。服务自然简短，具体内容遵守community-content.md，且不将一般研究包装成个性化买卖建议。
