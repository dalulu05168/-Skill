# P004 · 双 Skill 融合与角色发言准则（2026-10-11 设计草案）

> 范围：在原有 `romania-market-director`（人物/编剧）与 `romania-stock-intelligence`（财经新闻研究）两套技能上融合。本草案是角色表达与导演调度层的新增要求；不覆盖65人正式档案、历史记忆、真实发布系统、栏目时间，待角色逐人重设后再定稿。

## 本次用户确定的范围

- 总导演拥有故事制作最高调度权；用户可以临时增加插播/改稿任务，导演只重排**未正式采用或未转发**内容。
- 此轮不增加**图片生成 Skill**或**翻译 Skill**。原第4模块已有的图片修改/下载4K能力继续独立保存，不当成已经完成原生源码整合。
- 第2模块提供65人**模拟交易事实记忆**，不是人物性格库，也不做财经新闻编剧。买入/卖出事实可作为未来第4模块的买入/卖出通知图片的数据输入；图片不得反改交易记录，不伪装真实券商成交凭证。
- 65人是一部**从第一场开始创作的显著标识为虚构的财经教学群聊小说**：不得强行预填过去聊天、熟识关系、昨天争论或收益经验。固定人设由用户逐人确定；动态记忆只增录正式采用的情节。
- 前三段时间窗口由用户此前确认，但具体栏目尚在考虑，不能用旧16节点硬套未经确认的内容。教授仅晚间开讲，周一/三/五技术课、周二/四理念课；不在新风格草案中硬编码尚未重新确认的精确开讲分钟。

## 教授：本次重点修订（高影响优先）

**身份设定（虚构人物）：** 常驻罗马尼亚的美籍金融股票投资教授，讲授高度专业但平实。美籍/教授是作品设定，不等同真实执照、学历、院校、履历的可对外验证背书。

**出场职责：** 只负责晚间课堂，不抢白天助理职责。

**每天节奏：** 问候（短）→ 提炼当日一至两个真正相关的复盘重点 → 讲透一个核心知识点（定义、为什么、通俗生活比方、适用条件和反例）→ 自然带到课程/群组可真实提供的帮助或参与方式 → 具体作业 → 有激励力的晚安。

**周一/三/五技术课：** 趋势、价量、支撑阻力、市场结构、风险等。一次不堆砌太多概念。优先把**本日早上或下午已被确认的具体问题、案例或市场事实**转为比喻；若没有已采用的前文，就用显式的【假设】新案例，绝不声称“某成员上午已经问过”。

**周二/四理念课：** 围绕家庭、人生选择、退休、孩子教育、经济自由、责任感、主动学习、投资心理等真实生活动机设计问题、故事、正反案例。允许营销感与吸引力，但不能虚构真人成功案例、用户收益、承诺投资结果，不把对家庭的愿望转成强制投资或恐惧话术。

**结束语的正确方向：**
- 学什么：今晚一个有用的投资思维/判断方法。
- 用在哪里：明日的上市公司观察、财报理解、市场复盘、练习与适合自身条件的行动。
- 为了什么：逐步具备独立判断力，让自己和家庭有更多生活选择。
- 怎样参与：邀请成员明天继续参与讨论、练习和研究，提出问题、验证学到的知识。
- 激励方式：有力量、带期待、讲实际动作，而不是空泛“坚持学习”，也不是催促立刻买卖。

**风格示例（非已采用正式剧本）：**
“学会看趋势，不是为了背几根线。明天看市场时，请每个人试着选一家自己真正理解的公司，观察价格变化有没有成交量支持。把方法用起来，才可能让我们将来为家庭做决定时少一些盲目、多一些选择。积极参与、敢于提出问题，比沉默听完更有价值。晚安，明天见。”

## 助理：新闻说人话，运营植入不打断主线

- 比教授更亲切、更有情绪温度。每次新闻只讲**发生什么 / 与今天大盘或关注行业有什么关系 / 哪点还需观察 / 一个容易参与的问题**，不强制套固定四段。
- 对大盘的方向性论断必须有新鲜事实，不写无来源的“必涨”“庄家拉升”。财经研究 Skill 提供事实，助理负责转成普通人听得懂的话。
- 群成员可以跑题、激烈不同意、短暂沉默；助理只在场面失控、冒犯他人、事实错误或需要衔接课程时介入。不需要每条消息都点名主持。
- 活动植入用**具体礼品名称＋一行私信引导**，不单独占整场，也不编不存在的兑换规则。示例礼品候选：**投资学习笔记本、商务签字笔、保温杯**。礼品名称是脚本提案，正式对外使用前必须确认确有相应活动及可提供礼品。
- 示例（虚构宣传文案，非已发活动）：“签到互动的小礼品有学习笔记本、签字笔和保温杯。感兴趣的话私信我了解就好，咱们接着看今天的市场重点。😊”
- 不虚构中奖者、剩余奖品数、积分、门槛、收益成绩或已发私信；用户尚未决定的活动细则不擅自定制。

## 65名成员：主行为类型是倾向，不是每天表演的标签

建议可考虑追随者、观望者、质疑/反驳者、提问者、独立研究者、情绪型、生活/幽默型、少言型；同人可以同时有一项主倾向和一项副倾向。**分类与具体人数等待用户重新设计65人后确认，不自动批量改档案。**

每人独立记录：编号与固定身份、地区与职业、关注主题、说话长短、常用短语/口头禅、表情与标点、脏话使用边界、金融理解水平、参与频率、兴趣触发、沉默原因、面对质疑的反应。语言DNA不能只是复制几句模版。

**编剧选角必须有因果链：** 当前事件/个人兴趣/正式历史 → 为什么这人此时发言 → 会如何说 → 是否会被另一人具体回复 → 这段交流有什么后续。没有动机就可以不出场；允许一天仅发一个字、突然多说几句、下午接上午讨论、长时间保持不同意见，也允许因生活场景自然离题。可以有合理的口语粗话、冲突及调侃，但不制造无缘由辱骂或群体攻击，不把所有65人写成统一支持助理/教授。

**起始零记忆：** 第一场没有“我们前几天聊过”“你上次买了”等过去完成式剧情。先在当场发生并被正式采用，后续才可引用。

## 双轨记忆与第2模块

**发言/剧情记忆：** 已采用 scene_id + message_id + 角色编号 + 日期时段；保存实际说过的内容、未解问题、观点变化的原因和必要衔接，不硬塞人物关系史。

**交易事实记忆：** 第2模块已保存的 simulation_only 成交及持仓事件；必须以 person_id / holding_id / transaction_id 引用，严格区分计划、推荐、已买入、已卖出、当前持仓与盈利亏损。无记录＝未发生。剧本可以让角色自然提及自身已有的模拟交易，但不得当真人投资经历或客户盈利见证。

**第2→第4模块接口规划（此草案不实现）：** 确认成交的 buy/sell 事件 → 模板数据对象（模拟字样、人物编号、股票、价格、数量、记录时间、事件ID）→ 现有第4模块可编辑买/卖通知图 → 4K PNG 导出。第4模块独立、不可写回交易账本。暂不增加任何自动图片生成或翻译能力。

## 导演指挥与验收

1. 用户要求“几点到几点” → 新闻研究返回事件证据和影响 → 导演挑选话题与进程 → 读取所选人物及真实历史、必要时读取第2模块交易记忆 → 编剧生成对白／晚课 → 自动检查。
2. 中途插播优先重新安排**尚未采用/尚未发送**内容，不改过去事实，不把示例作为已经发布；对新事实产生冲突时追加更正/待核条目。
3. 自动可阻断：人物编号/身份错、发言记忆引用不存在、模块二交易凭空引用、未经证实的财经数值、教授白天错误出场、已采用会话被无授权覆盖、已知语言DNA硬违例。
4. 需要实质审读、不得“自动合格”：教授的吸引力与讲课深度、成员像真人而非模板、生活动机是否可信、营销是否自然、罗马尼亚语口语是否恰当。机器/模型只能给出带证据的检查意见和退稿修改，不能自称审美和事实100%通过。
5. 必备压力样例：第一天零记忆；上午有真实问答下午再次提起；模块二有/无成交的两类成员；两人因同一新闻产生合理争执；晚间教授引用当天事实作类比；签到活动提到礼品但无编造条款；数据获取失败时降级为不依赖当日数字的学习内容。
