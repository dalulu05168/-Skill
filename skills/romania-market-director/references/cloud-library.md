# 云端统一资料库

不要要求用户为人物建立独立窗口。当前仓库作为正式共享资料源，当前执行环境内直接按路径读取。

开始任务先读取library/index.json，再读取相关规则、人物及memory/state.json。资讯从library/news/选日期匹配资料；课程从library/technical-courses/或references/course-plan.md读取；GIF从library/gif/选择真实存在素材；原始聊天在library/source-chats/。已采用稿仅取library/approved/，草稿不替代历史。

用户上传或粘贴资料后，保存原件或原文并登记索引，注明原始来源、日期、状态和版本。只收集任务需要内容，不保存凭证或无关私人信息。每日资讯仍需检验来源和口径；文件存在不等于事实已核验。

跨对话/其他GPT不能假定自动访问本云端磁盘。能访问仓库的任务读取仓库；否则上传最新版ZIP。资料包包括库内容，较大GIF可以保留仓库引用并解释访问需求。其他窗口的推送不会自动入库，仍需一次上传、粘贴或已配置连接器导入；不声称后台自动同步。

当前原始三份聊天及表情DOCX已保存，65份档案已完整保留。技术课与每日新闻未收到时，明确说明缺项，不造文件或声称已调取。

GIF资料已由用户上传导入，读取library/gif/catalog.json；本地与在线状态必须区分。

## 用户修改定稿的正式归档
用户明确认定当日修改版“采用/定稿/存档”后，在有权限时，按`scene_id`写`library/approved/`用户改定的原稿，更新`memory/state.json`的人物观点、回应、Emoji/GIF/八项使用历史及未决问题，再登记`library/index.json`；保留版本和修改来源，不静默覆盖旧稿。用户仅提供审阅稿则不改正式记忆。可按明确授权和已连接云盘路径保存副本，**仓库更新不代表云盘自动同步**。固定`characters/profiles/`不得改写。
