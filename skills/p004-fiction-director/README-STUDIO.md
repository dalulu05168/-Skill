# P004 可操作导演工作台（独立开发分支）

**目的：** 把新故事的导演、编剧、教授、助理、65名候选人物接成一套可以本机打开、真正点按钮操作的审稿流程；它不等于已上线的四合一生产版本。

## 一键启动（Windows）

进入本目录，双击 START-DIRECTOR.cmd。需要 Python 3.11 或更高，使用内置标准库，不需 pip 安装依赖。启动后自动打开 http://127.0.0.1:8765/

CMD 窗口持续显示服务状态，程序报错时窗口不会立即闪退。只监听 127.0.0.1，不允许外网直接访问。

1. 选择罗马尼亚故事日期、时段、话题，点击 **真实选角 · 创建场次**。执行现有 director_cast / director_workflow，展示选中的候选成员、导演提示和教授课程类型。成员可以不发言。
2. **真实AI生成：** 先在同一 CMD 终端启动前，配置本机 Ollama 并下载支持罗马尼亚语和 JSON 的模型。例如首次运行 ollama pull qwen2.5:7b，启动程序前执行 set P004_OLLAMA_MODEL=qwen2.5:7b，点击 **调用本地 AI 编剧**。服务器会真的请求本机 127.0.0.1:11434/api/chat，使用 JSON 输出约束，最多3轮结构审稿/重写。模型不存在/未启动/超时将显示失败，**绝不用假对白代替实际模型响应**。本程序不会下载模型，也不保证硬件能运行该模型。
3. **不用安装模型也可审稿：** 点击 **复制编剧提示词**，交给你正在使用的 ChatGPT 获取 JSON，再粘贴到右侧，点击 **实际校验剧本**。只有通过结构和身份检查才会显示待人工审稿。
4. **正式采用：** 通过编辑和操作者双重确认，且新65人名单已逐人明确批准，才能调用 approve_scene.finalize 写入 SQLite。当前 characters/approved-roster.json 仍为空，所以按钮被关闭，后端同样阻止写入。要批准人物必须走专门审核过程，**不要为了让按钮变绿就自动把草稿都标为批准**。
5. 浏览器刷新可通过会话 token 恢复本机保存的草稿。文件默认保存到用户主目录 .p004-director/drafts/；真正已采用的历史保存在 .p004-director/adopted-scenes.sqlite3。退出本机服务不会丢掉草稿文件；备份该目录可迁移本地内容。

## 检查

从仓库根目录执行 Python unittest discover（目录 skills/p004-fiction-director/tests），或查看 PR 对应 P004 Independent Fiction Director QA GitHub Actions。测试中模型回调使用明确标注的测试替身，**不代表真实 Ollama 或跨模块生产链路已经验收**。

这套工具的小说人物必须在作品层清晰披露虚构属性；禁止将对白伪装成真实投资客户的发言、见证或收益证明。
