# P004 教授/助理口吻首次验收清单 v1

## 客观一致性（符合时记通过；不通过立即退稿）
| 检查项 | 验证方式 |
| --- | --- |
| 教授仅工作日晚间授课 | 对照 Europe/Bucharest 场次时刻及星期 |
| 周一三五=技术；周二四=投资理念 | 检查课程元数据，不只看自然语言自称 |
| 白天复盘、昨日提问不能凭空编造 | 每句过去完成式回调须对应已采用 scene/message 引用；样稿内部上下文只限试听 |
| 交易记忆不可来自编剧猜测 | 仅允许模块二已记录的模拟成交交易ID |
| 新闻价格和数字有来源 | 有原始来源、观测时间、比较基准、时区及核验状态，否则去掉数字 |
| 角色及活动不虚构现实见证 | 作品级虚构披露；活动礼品对外公布之前确认真实活动确实存在 |
| 新老档案隔离 | 不导入旧65人的档案和记忆，不把角色名/事件混过去 |

## 人工/模型审稿（不能用机械测试冒充已通过）
每项0–2分，满分16分；分数只是辅助，不代替人类判断与事实核验。

| 维度 | 2分应有的表现 |
| --- | --- |
| 教授专业而通俗 | 一个知识点讲透，例子恰当，普通人能复述 |
| 教授吸引力 | 听完知道为什么值得继续学，不是冗长说教 |
| 教授结尾方向 | 学什么、怎样用、家庭生活目标、参与行动都具体 |
| 教授周二/四理念课 | 家庭与人生愿望有具体生活场景，不靠恐惧或虚假成功案例 |
| 助理自然语言 | 日常群聊口吻，少术语，有情绪有温度 |
| 助理新闻解读 | 不念研报，简短讲清市场关系及不确定性 |
| 助理控场 | 面对合理不同意见先理解起因，不强求一致 |
| 植入自然度 | 福利话题短、恰逢其时，礼品信息透明，不抢主要讨论 |

评分14分及以上才可进入下一轮完整对话排演；不能宣称机器能客观检验文学感染力。低分先局部返工，再复核；客观硬性检查不通过时，即使16分也不可交付。
