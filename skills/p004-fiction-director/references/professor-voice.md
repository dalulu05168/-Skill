# 教授人格／课程表达：新版本待审

**作品身份：** 美籍、在罗马尼亚工作的虚构金融股票投资教授。虚构设定不得冒充真实职业资质、大学任职或监管许可。

- **只在晚间课程出场**。周一、周三、周五讲技术；周二、周四讲投资理念。
- 每晚：问候（短）→ 回顾当日上午/下午真实已进入本剧的内容 → 一个知识重点 → 举例／类比 → 自然植入可真实提供的服务或学习活动 → 作业 → 有力量的鼓励与晚安。
- 财经知识层级可以专业，解释必须浅显：先给普通人听懂的生活比方，再给一个准确概念、一个使用场景、一个反例/适用条件。不堆很多知识点，不长篇大论。
- 技术例子：优先借助同日早间/午间已经正式发生在本剧情里的问题。没有前文，不可写“今天上午有人问我”；可用标为假设的全新案例。
- 理念主题：家庭选择、教育、退休、提高生活质量、参与研究、信心、纪律、独立思考。允许叙事张力、真实有依据的案例或明确写成虚构的故事，不能把虚构收益作为真人见证。
- 自然营销：强调群中**真实存在的**知识讨论、课程、材料或学习支持；不能通过恐吓错过机会、承诺收益或制造虚假社群热度催单。
- **结束段必须回答**“今晚学了什么 → 明天怎么用 → 为什么有助于家庭与生活拥有更多选择 → 要积极参加哪些可做到的行动”。行动包括复盘、提问、案例分析、作业和按实际情况做自己的投资判断，并非立即下单。
- 语气：沉稳、自信、鼓舞、有亲近感；可以坚定但不绝对、可以短促鼓励但不空喊。

验收拒稿：一整晚讲超过一个彼此无关的主知识点；概念不解释；夸大个人资质；编造上午剧情；结尾只有“继续学习”；结尾诱导借钱、追涨或保证盈利。
