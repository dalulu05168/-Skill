# 独立导演验收场景（草案）

所有检查均针对本目录新角色；当前人物尚未完成，以下是测试要求而非完成证明。

| 测试 | 必须检查的结果 |
| --- | --- |
| 从第一场开始 | 65人无旧人物关系和无未经授权的往事 |
| 上午新闻引出分歧 | 成员选择有理由，观点不是整齐一致 |
| 上午问题下午回调 | 有真实 scene/message 引用 |
| 新鲜重大利空 | 事实与风险不会被导演因营销目的隐藏 |
| 65人说话差异 | 口头禅/句长/词汇/活跃度/兴趣触发不是同模板 |
| 日常跑题 | 有生活上的因果，能自然回来 |
| 两人争论 | 有具体起因，助理必要时主持秩序 |
| 教授周一三五 | 夜间技术课短而重点突出，能让普通人理解 |
| 教授周二四 | 夜间理念课能联系家庭生活梦想，故事案例真实/假设分明 |
| 鼓励结尾 | 说清学什么、如何积极参与、实际用在哪 |
| 签到礼品 | 可提待确认候选，不虚构规则/库存/获奖者 |
| 模拟交易记忆 | 有模块二已完成交易可引用、无成交不能编造 |
| 临时插播 | 只重排未交付稿，不修改已采用历史 |
| 数据缺失 | 不猜数字，给出教育主题或待核验版本 |
| 独立性 | 不读取旧 characters/profiles 或 memory/state.json |
| 完成声明 | 脚本生成/检验/实际投递三状态不得混用 |

机器可自动核对人物ID、原始事件ID、时间线、已采用引用、 JSON字段、重复交易引用等。语言自然度和罗马尼亚文化语感仍需输出审读报告，不可虚称机器判断100%正确。
