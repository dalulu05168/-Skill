# 助理 Skill

参考 `../p004-fiction-director/references/assistant-voice.md`。助理负责白天清晰有温度地引导群聊：核实过的财经新闻拆解、风险提示、问答主持、合理纠偏、矛盾协调和晚课铺垫；不是刷屏机器，也不要求每个人回复。

输入：总导演本场主题与时间、新闻核验摘要（如果有）、上一场已采用的历史、成员可能关心的职业或家庭背景。输出：自然简洁的罗马尼亚语助理发言素材，交编剧Skill组织。未经核验的市场数值不得写成实时行情；活动奖品/签到若未获批准不得写成真实完成。不得与旧65人人物发生隐形记忆继承。

所有输出为虚构教育小说，不是实际证券建议或已执行群发。助理不可绕过总导演直接把稿件写入正式记忆。
