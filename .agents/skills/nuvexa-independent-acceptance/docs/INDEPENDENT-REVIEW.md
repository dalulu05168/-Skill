# 独立验收员真实用户走查清单

> 此表必须由没有参与代码实现的验收员根据**实际运行的页面**和本次测试截图填写。不能照抄开发者的自评。

## A. 进入系统

- [ ] 页面可真实打开，首次加载、刷新、直接访问二级路由不白屏
- [ ] 浏览器/服务器控制台无关键未处理异常
- [ ] 所有必需模块、按钮、标题、统计项显示完整，不允许缺少信息、文字溢出或压线
- [ ] 桌面 16:9 视图是否符合产品对非滚动界面的要求；移动屏幕是否可用
- [ ] 切换模块、返回、前进、刷新时，实际数据和状态不意外消失

## B. 登录、角色、数据

- [ ] 不输入密码、错误密码、已退出登录时，无法访问受保护模块
- [ ] 实际测试对应的权限角色，每一种角色只看到允许访问的页面和数据
- [ ] 2FA 开启的角色必须测试过期码、错误码、正常码；**不得通过绕过 2FA 验收**
- [ ] 网页前端信息与真正后端 API、数据库或权威数据源一致；不得用假统计数充数
- [ ] 搜索真实结果、空结果、错误输入、清空条件、分页切换均有正确反馈
- [ ] 每个可见按钮都要实际点击；不工作的按钮不算通过

## C. 关键业务与错误复现

- [ ] 先复现原报告故障，再在修复版本完整复测相同路径
- [ ] 对失败/网络断开/超时/重复提交有明确安全处理，不静默成功
- [ ] 保存、编辑、删除涉及真实数据的动作只在测试库执行，并有明确回滚方案
- [ ] 资金、交易、提款、充值、授权等高风险流程分别测试授权，绝不在真实账户试单
- [ ] 所有执行记录、日志和截图有可追溯的对应步骤、运行时间及代码版本

## D. UI 专项

- [ ] 对照用户实际确认的设计稿，而非随机 AI 审美判断
- [ ] 字体、按钮、控件、卡片、边线、留白、响应式断点一致
- [ ] 验证 16:9 宽屏、窄屏、手机竖屏及信息多时的布局
- [ ] 文本放大、表单错误、空数据、加载中、掉线、无权限状态的画面可用
- [ ] 页面截图与实际浏览器运行一致；不是静态假图

## E. 最终状态

- **PASS**：必要测试已执行，所有失败已修复并回归通过；安全与项目适配要求满足
- **REJECTED**：任一必要步骤失败、缺少配置或不存在可核验证据
- **UNVERIFIED**：环境/账号/API/浏览器阻止了实测（技术门禁仍按拒绝处理）

## 外部发布审批

技术自动化即使 `PASS`，也不等于可以生产上线。需要单独的代码审核、发布授权、备份/回滚机制和仓库保护规则。确保生成的验收报告不会被提交者自行改成 PASS 以后绕过 CI。
