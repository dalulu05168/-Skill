# V2.1 修正与使用说明

- 空 observations 返回 fail；CLI 退出码 1，不能把无数据作为行情审核通过。
- 官方来源严格匹配 allowed_hosts（未设置则仅接受 uri 域名）；BVB 明确允许 bvb.ro 与 www.bvb.ro，不自动信任任意子域名。
- BET 完整归因必须有 previous_trading_close_at、returns_baseline_at、session_source_url、session_evidence_locator，以及 official_roster、roster_source_url、roster_evidence_locator、roster_as_of。权重与回报基准必须精确匹配已提供的上一交易日收盘；成分名单须为回报所在交易日且不晚于回报时点。缺少证据时 qualified_full_index_attribution=false；矛盾证据拒绝处理。
- 上一交易日由官方交易日历/时段证据确定，不能凭周一至周五推断；代码检查所提供元数据的一致性，不会自行读取页面证明真实性。
- 新增 INS、S&P DJI、Nasdaq、美国财政部官方入口，未宣称已访问、已取得报价或拥有实时授权。

## 验证

Python 标准库测试：55项通过，0失败。所有 synthetic 文件仅为测试，未写入真实行情库或成员记忆。

## 调用

在仓库 .agents/skills/romania-stock-intelligence 中运行：

```sh
python scripts/rsi_v2.py audit /path/to/observations.json --out /path/to/audit.json
python scripts/rsi_v2.py bet /path/to/bet-input.json --out /path/to/bet-result.json
python scripts/validate_report.py /path/to/report.json
```

审核 fail 时隔离问题数据；pass_with_warnings 逐项处理过期或延迟；pass 仅代表元数据检查通过，仍需核对原文。合格数据供导演 Skill 选择、讲解和安排教育性对话。未获取今日数据则输出资料缺口，不从示例生成当前行情。推送与定时任务尚未启用。
